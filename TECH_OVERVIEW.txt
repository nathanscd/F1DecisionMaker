PROJECT SUMMARY
--------------------------------------------------------------------------------
F1 Decision Maker is a data-driven strategic analysis platform for Formula 1.
The core research question is:
  "Does a driver's final position have a direct relationship with the
   pitstop strategy adopted?"

It is an academic project (Big Data in Python course) that uses statistics,
data analysis, and machine learning — no generative AI / LLMs.

Data sources: F1 seasons 2023 and 2024 (and partially 2025), obtained from
the OpenF1 public API and processed into CSV datasets.

================================================================================
  BACKEND
================================================================================

Language        : Python
Purpose         : Data collection, cleaning, feature engineering, CSV export
No active server: backend is currently offline / pre-processing only

--- Files ---

backend/app/create/DatasetCreate.py
  - Main ETL script
  - Calls OpenF1 REST API endpoints: sessions, laps, position, stints,
    drivers, weather
  - Handles: rate limiting (429), invalid endpoints (422), retries
  - Engineers features per pit stop / stint:
      pit_lap, pit_duration (estimated), compound, tire_age,
      position_before_pit, position_after_pit, pit_position_loss,
      avg_lap_stint, best_lap_stint, weather averages
  - Saves partial (incremental) and final CSVs

backend/app/test.py
  - Single-driver exploratory script for one race session
  - Demonstrates the merge pipeline:
      laps ← positions (merge_asof by timestamp) ← stints (expanded by lap)
  - Detects pitstops via stint change OR pit API endpoint (OR logic)
  - Computes: tire_age, lap_time_delta, rolling_pace (3-lap rolling mean),
    degradation (lap_time − first lap of stint)
  - Outputs a clean CSV for validation

================================================================================
  MACHINE LEARNING / ANALYTICS (all runs client-side in TypeScript)
================================================================================

k-Nearest Neighbors (insightService.ts)
  - Compiles historical cases from lap data
  - Normalises features with min-max scaling
  - Weighted Euclidean distance:
      pit_count ×1.0, pit_lap ×1.5, tire_age ×0.8,
      degradation ×1.0, rolling_pace ×2.5, position_before_pit ×2.0
  - Compound mismatch penalty: +0.25 to distance
  - Outputs: expected final position, expected position change,
    probability bands (Podium / Top5 / Points / Outside Points),
    confidence score (0–100%)

Analytics (analyticsService.ts)
  - Strategy efficiency comparison (1-stop vs 2-stop vs 3-stop)
  - Pearson correlation between strategic variables and final position

Statistics (statisticsService.ts)
  - Correlation matrices, distributions, scatter data

Simulation (simulationService.ts)
  - Alternative timeline: re-runs race scenario with different pitstop params
  - Estimates outcome based on historical patterns

Custom Metrics computed from data:
  Strategy Efficiency Score
  Tire Management Score
  Consistency Score
  Position Recovery Score
  Pit Stop Efficiency Index
  Undercut / Overcut Effectiveness Score

================================================================================
  HOW TO RUN
================================================================================

Frontend (main app — fully self-contained):
  cd frontend
  npm install
  npm run dev
  → Runs at http://localhost:5173

Backend (data collection scripts only):
  cd backend
  python -m venv .venv
  .venv\Scripts\activate          (Windows)
  pip install requests pandas
  python app/create/DatasetCreate.py
